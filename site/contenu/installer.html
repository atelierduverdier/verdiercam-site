01 · Linux, sur PC

Debian, Ubuntu, Mint, Fedora, Arch…

Le paquet est une archive VerdierCAM-version-linux-x86_64.tar.gz. Clic droit, Extraire ici : il en sort VerdierCAM-version-linux-x86_64.AppImage, prêt à lancer d'un double-clic. L'archive garde le droit d'exécution, qu'un téléchargement direct perdrait. Toute distribution de 2022 ou après convient.

Si le double-clic ne lance rien, il manque souvent la petite bibliothèque qui ouvre les AppImage. Sur Debian 12 et Ubuntu 22.04 :

sudo apt install libfuse2

Sur Ubuntu 24.04 et après, elle s'appelle libfuse2t64. Ou, sans rien installer, depuis un terminal :

./VerdierCAM-*-linux-x86_64.AppImage --appimage-extract-and-run

L'affichage passe par Vulkan. Avec une carte AMD ou Intel, le pilote libre suffit (sudo apt install mesa-vulkan-drivers sur Debian et Ubuntu) ; avec NVIDIA, le pilote de NVIDIA.

02 · Windows

Windows 64 bits

Le paquet est un fichier VerdierCAM-version-windows-x64.zip. Clic droit, Extraire tout, puis VerdierCAM.exe dans le dossier obtenu : c'est le seul fichier à lancer. Le dossier programme, à côté, contient tout le reste du logiciel ; il reste avec lui.

Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » : le programme est neuf, son éditeur pas encore connu de Windows. Cliquer Informations complémentaires, puis Exécuter quand même. Ou, avant d'extraire : clic droit sur le .zip, Propriétés, cocher Débloquer.

Un antivirus (Avast, AVG…) peut aussi le retenir quelques heures, le temps d'analyser ce programme qu'il ne connaît pas encore : « Il faudrait qu'on regarde cela de plus près ». Attendre la fin de l'analyse, ou mettre le dossier de VerdierCAM dans ses exceptions.

Extraire le dossier hors de OneDrive — dans C:\VerdierCAM, par exemple. Le Bureau et les Documents sont souvent synchronisés : OneDrive bute sur les centaines de fichiers du dossier programme, et le logiciel peut ne plus démarrer.

03 · Raspberry Pi 5

Raspberry Pi 5, système 64 bits

VerdierCAM tourne aussi sur un Raspberry Pi 5, sous un système 64 bits : un poste d'atelier à côté de la machine, pour retoucher un dessin, simuler et piloter. Le paquet est VerdierCAM-version-linux-aarch64.tar.gz. Il a été essayé sur un Pi 5 de 8 Go.

Sous Raspberry Pi OS 64 bits, le système à jour, puis la bibliothèque des AppImage :

sudo apt update && sudo apt full-upgrade
sudo apt install libfuse2 mesa-vulkan-drivers
sudo apt install --no-install-recommends zenity

zenity dessine la fenêtre « Ouvrir un fichier » : sans lui, Ouvrir et Enregistrer ne montrent rien. Raspberry Pi OS l'a souvent déjà ; la commande ne fait alors rien.

Puis, dans le dossier du téléchargement :

tar xzf VerdierCAM-*-linux-aarch64.tar.gz
./VerdierCAM-*-linux-aarch64.AppImage

Vérifier que la carte graphique du Pi est bien utilisée : sans elle, tout fonctionne, mais lentement.

sudo apt install vulkan-tools
vulkaninfo --summary | grep -i devicename

La ligne doit dire V3D 7.1. Si elle dit llvmpipe, le pilote graphique est trop ancien pour le Pi 5 : voir le cas suivant.

Le Pi est moins puissant qu'un PC : le dessin, l'usinage et la simulation y sont à l'aise, les calculs lourds (simulation en finesse « fine », grands reliefs, relief par IA) prennent nettement plus de temps.

04 · Pi sous Debian 12 ou LinuxCNC

Un Pi 5 sous Debian 12, ou l'image LinuxCNC

C'est le cas du Pi qui pilote la machine de l'atelier : Debian 12 avec le noyau temps réel de LinuxCNC. Son pilote graphique (Mesa 22.3) date d'avant le Pi 5 : Vulkan y tourne sur le processeur (llvmpipe), et VerdierCAM rame. Le remède : le Mesa plus récent des backports de Debian 12. Il ne change que les pilotes graphiques, ni le noyau temps réel ni LinuxCNC.

LinuxCNC fermé, machine à l'arrêt. Si les backports ne sont pas déjà dans les sources :

echo "deb http://deb.debian.org/debian bookworm-backports main contrib non-free non-free-firmware" \
  | sudo tee /etc/apt/sources.list.d/backports.list
sudo apt update

Puis les pilotes graphiques, et un redémarrage :

sudo apt install -t bookworm-backports mesa-vulkan-drivers libgl1-mesa-dri libglx-mesa0 \
  libegl-mesa0 libgbm1 mesa-va-drivers mesa-vdpau-drivers
sudo apt install libfuse2
sudo apt install --no-install-recommends zenity
sudo reboot

Ensuite, vulkaninfo --summary doit dire V3D 7.1, et VerdierCAM s'installe comme au paragraphe précédent. Relancer LinuxCNC et faire un mouvement à vide avant une vraie pièce : son écran passe aussi par le nouveau pilote.

Si le curseur de la souris clignote (bureau Xfce, comme sur l'image LinuxCNC) : couper la composition des fenêtres. Seules les ombres sous les fenêtres disparaissent.

xfconf-query -c xfwm4 -p /general/use_compositing -s false

Un souci ? contact@verdiercam.fr, avec la sortie de vulkaninfo --summary.
